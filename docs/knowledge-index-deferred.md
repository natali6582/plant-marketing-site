ה־renderer המשותף שהוסר היה ב־`src/components/knowledge/HubPage.astro`, שורות 105–121:

```astro
      <ul class="mt-8 grid gap-5 md:grid-cols-2">
        {
          REGULATORS.map((r) => (
            <li
              class:list={[
                'reveal card-lift rounded-2xl border bg-white p-6 shadow-sm hover:border-brand-400',
                r.venue ? 'border-dashed border-brand-300' : 'border-brand-200',

              <h3 class="mt-3 text-lg font-bold text-brand-800">{r.name}</h3>
```

כדי לשחזר את ה־renderer יש להחזיר גם את `scope: string` ל־`Regulator`, את שדות `scope` לאחר אימות, את `REGULATORS` לייבוא של `HubPage.astro`, ואת הבלוק לעיל.
