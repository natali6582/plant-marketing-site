הנחות החישוב — גלויות לאורך כל הדרך

התשואה והאינפלציה קבועות בתרחיש. שיעור שנתי מומר לחודשי לפי (1 + r)^(1/12) − 1. דמי הניהול מצבירה מחולקים ב־12 ונגבים בכל חודש אחרי התשואה.

הפקדה נטו נכנסת בתחילת החודש. משיכת תחילת חודש קודמת לתשואה; משיכת סוף חודש מתבצעת אחרי התשואה ודמי הניהול. החישוב אינו כולל מס, עלויות נוספות או תנאי מוצר.

ברירות המחדל הן מספרים לדוגמה. ההפקדות קבועות בסכומן הנומינלי. ההצמדה, אם הופעלה, מתחילה במשיכה השנייה.
